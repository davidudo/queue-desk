# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-27

### Added

- Initial production-grade QueueDesk monorepo (`@queuedesk/shared`, `@queuedesk/api`, `@queuedesk/web`).
- PostgreSQL schema, migration runner, and deterministic synthetic data seeder.
- RBAC authentication, ticket management, operations dashboard, and admin console.
- Unit, integration, and Playwright E2E test suites.
- Dockerfiles, Nginx reverse proxy, Docker Compose, GitHub Actions CI/CD, and Autocannon/EXPLAIN benchmarks.
